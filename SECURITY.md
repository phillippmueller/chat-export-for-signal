# Security policy

## Reporting a problem

If you find a security problem, for example a way the tool could leak message
data, write outside the chosen export folder, or run code it shouldn't, please
report it privately rather than in a public issue:

- **Preferred:** use GitHub's private
  [Report a vulnerability](https://github.com/phillippmueller/chat-export-for-signal/security/advisories/new)
  form.
- **Or email:** SUPPORT_EMAIL_PLACEHOLDER with "Security" in the subject.

Please include what you did, what happened, and the output of
`signal-export.sh version`. You'll get a first reply within 7 days.

## Supported versions

Only the latest release receives fixes.

## Scope

Problems in signal-export itself belong upstream at
https://github.com/carderne/signal-export. If you're unsure where an issue
belongs, report it here and it will be forwarded.
